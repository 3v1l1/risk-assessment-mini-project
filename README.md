# Mini Risk Assessment Project

This project demonstrates foundational risk assessment skills based on asset identification, threats, and vulnerabilities.

---

## Scenario

A small company uses:
- A public website
- Employee laptops
- A shared internal database

---

## Step 1: Identify Assets

- Web server
- Customer data
- Employee credentials
- Internal database

---

## Step 2: Identify Threats

- Phishing attacks
- Malware infection
- Unauthorized database access
- DDoS attacks

---

## Step 3: Identify Vulnerabilities

- Weak passwords
- Outdated software
- Lack of multi-factor authentication
- No regular backups

---

## Step 4: Risk Evaluation

Example:

Risk: Phishing attack leading to credential theft  
Impact: High  
Likelihood: Medium  
Risk Level: High

---

## Step 5: Recommended Controls

- Implement MFA
- Regular software updates
- Security awareness training
- Network monitoring

---

## Conclusion

This mini project demonstrates basic asset identification, threat modeling, and risk mitigation strategies.
